The preset examples below all use the same illustrative ratio:

1 200 = 0.0000001 ETH  ·  10,000,000 200 = 1 ETH

At a fixed total supply of 100,000,000 200, that ratio implies an FDV of 10 ETH. This is an illustration, not a chosen launch valuation.

DEX implementation note

The Base Sepolia validation used PancakeSwap V2 because it gave us a simple, testable LP lifecycle. For Base mainnet, the final DEX version and current official deployment contracts will be re-verified immediately before launch. The initial token/ETH ratio can be chosen independently of that implementation decision.
